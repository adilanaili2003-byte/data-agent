# 运行示例 & 截图清单

本文档给出**可复现的运行步骤**、**真实运行结果**，以及做演示/作品集时需要截取的**截图清单**。

---

## 一、运行前准备（按顺序各跑一次）

```bash
# 1. 配置 API Key（把 .env.example 复制为 .env，填入 DEEPSEEK_API_KEY）
# 2. 建库造数
python seed_db.py
# 3. 建 Schema RAG 索引（首次会下载 bge-small-zh 模型，约 100MB）
python schema_rag.py build
```

> 依赖安装：`pip install -r requirements.txt`

---

## 二、命令行版（CLI）

```bash
python main.py
```

启动后输入问题，例如：

```
你：帮我分析最近三个月各地区的销售额，找出下降最明显的地区
```

Agent 会自动执行 `get_schema → run_sql → analyze_data → make_chart → write_report`，并在控制台打印每一步工具调用。

### 真实运行结果摘要

> 完整报告见 `reports/report_20261108_173426.md`

| 地区 | 10 月环比 | 10 月 vs 8 月 |
|---|---|---|
| 华东 | +19.9% | +2.7% |
| 华北 | +21.9% | **+32.9%** |
| 华南 | +25.1% | -8.8% |
| 西南 | **-56.4%** | **-64.7%** |

**结论**：西南地区下降最明显（10 月只剩 8 月的 35%），主因是订单量崩塌（134 单 → 44 单），判定为需求端/客户流失型下滑。

## 三、网页版（FastAPI）

双击 `启动网页版.bat`，或命令行：

```bash
python webapp.py
```

浏览器自动打开 `http://127.0.0.1:8008`，输入问题点击发送即可。

### 真实运行结果摘要

> 完整报告见 `reports/report_20261108_174852.md`

问题「各品类的销售额及占比」→ 结论：**食品**销售额最高，约 290.32 万元，占比 **23.36%**；五品类分布相对均衡（17%~23%），差异主要来自客单价。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 控制台中文乱码 | 先执行 `chcp 65001`，或 `set PYTHONIOENCODING=utf-8` |
| 端口 8008 被占用 | 改 `webapp.py` 里的 `PORT` |
| 首次跑 `schema_rag.py build` 很慢 | 正在下载 bge-small-zh 模型（约 100MB），只需一次 |
| 提示缺 `.env` / 数据库 / 索引 | 按「一、运行前准备」三步依次执行 |
